How does javascript control web and ur browser? So, basically there are two ways javascript control ur browser: BOM and DOM. BOM BOM stands for Browser Object Model, with it we can give special instructions over browser. In example: an attribute called ‘window’ we can make the browser show pop-up message with running alert() method in browser console. DOM DOM stands for Document Object Model, it is just like BOM, but we access it using global object called documents.

Standard Library - File System

January 17, 2022 • By dhymas • [NodeJS]

File system merupakan standard library yang bisa digunakan untuk memanipulasi file system. Terdapat 3 jenis library dalam File System, yakni: Library yang bersifat blocking atau synchronous Library yang bersifat non-blocking atau asynchronous menggunakan callback Library yang bersifat non-blocking atau asynchronous tapi menggunakan promise Untuk dokumentasi lebih lanjut dapat di lihat disini Author sendiri menyarankan menggunakan promise, karena lebih mudah, dan juga bisa menggunakan async await. Jika menggunakan callback, kita harus menggunakan callback terus menerus, dan malah menyebabkan callback hell.
