Standard Library - Debugger

By dhymas • January 21, 2022 • Categories: [NodeJS]

Halo semua, kembali lagi bersama Author :')

Postingan kali ini melanjutkan catatan tentang standard library bawaan NodeJS. Silahkan dibaca jika berkenan, semoga bermanfaat!

Mengenal Debugger di NodeJS

Jangan Cuma Andalkan console.log() Mulu, Thor… :v

Siapa di sini yang kalau ada bug di aplikasinya, langsung nebar puluhan baris console.log("sampe sini 1"), console.log("sampe sini 2")? Wkwk…

Ngga salah sih, Author dulu juga sering banget begitu. Tapi kalau kodenya udah mulai kompleks dan bercabang banyak, cara itu malah bikin layar terminal penuh sampah dan pusing sendiri.

Untungnya, NodeJS secara default sudah menyediakan standard library Debugger untuk membantu kita melakukan debugging kode baris per baris tanpa perlu install tool tambahan.

Cara Menggunakan Kata Kunci debugger

Untuk menandai titik di mana kode kita harus berhenti (dikenal dengan istilah breakpoint), kita cukup menuliskan kata kunci debugger; di dalam kode JavaScript kita.

Contoh, buat file bernama debug-test.mjs:

function hitungTotal(harga, jumlah) {
    debugger; // Eksekusi akan dijeda di sini!
    const subtotal = harga * jumlah;
    const diskon = subtotal * 0.1;
    debugger; // Jeda kedua untuk memeriksa nilai diskon
    return subtotal - diskon;
}

const totalBelanja = hitungTotal(50000, 3);
console.info(`Total bayar: ${totalBelanja}`);

Menjalankan Script dengan Mode Inspect

Jika kita menjalankan file tersebut hanya dengan perintah biasa node debug-test.mjs, maka kata kunci debugger; akan diabaikan begitu saja.

Agar debugger-nya aktif, jalankan menggunakan argumen inspect:

node inspect debug-test.mjs

Maka NodeJS akan membuka debug console interaktif:

< Debugger listening on ws://127.0.0.1:9229/...
< For help, see: https://nodejs.org/en/docs/inspector
Connecting to 127.0.0.1:9229 ... ok
break in debug-test.mjs:1
> 1 function hitungTotal(harga, jumlah) {
  2     debugger;
  3     const subtotal = harga * jumlah;
debug>

Beberapa perintah navigasi utama di CLI debugger:

  • c (cont / continue): Melanjutkan eksekusi sampai menemukan titik debugger berikutnya.
  • n (next): Menjalankan baris berikutnya (step over).
  • s (step): Masuk ke dalam fungsi (step into).
  • o (out): Keluar dari fungsi saat ini (step out).
  • repl: Membuka REPL interaktif untuk melihat dan memanipulasi variabel secara langsung saat program sedang berhenti!

Ketik repl, lalu ketik nama variabel seperti harga atau subtotal untuk mengecek nilainya saat itu juga.

Debugging Lewat Google Chrome (Lebih Nyaman!)

Kalau kalian kurang nyaman debugging lewat CLI terminal hitam putih, kita bisa pakai Chrome DevTools, loh!

Jalankan script dengan:

node --inspect-brk debug-test.mjs

Lalu buka browser Chrome, dan akses alamat: chrome://inspect

Klik tombol inspect pada target NodeJS yang terdeteksi. Seketika layar visual DevTools yang biasa kita pakai di frontend akan terbuka lengkap dengan panel Call Stack, Scope Variable, dan tombol Resume/Step Over. Keren banget kan?

Sekian catatan singkat dari Author mengenai debugger bawaan NodeJS kali ini. Semoga membantu teman-teman dalam mencari akar masalah bug tanpa harus banjir console.log() lagi, hehe…

Sampai ketemu di postingan standard library berikutnya! :)
