Javascript in Action

By Dhymas Julyan Riyanto • April 14, 2026 • Categories: [Javascript]

How does javascript control web and ur browser?

So, basically there are two ways javascript control ur browser: BOM and DOM.

BOM

BOM stands for Browser Object Model, with it we can give special instructions over browser. In example: an attribute called ‘window’ we can make the browser show pop-up message with running alert() method in browser console.

// Pop-up dialog
window.alert("Hello from BOM!");

// Check screen width
console.log(window.innerWidth);

// Check current URL
console.log(window.location.href);

Since window is the global object in browser environments, you can call these directly without typing window. (e.g. alert() or location.href).

DOM

DOM stands for Document Object Model, it is just like BOM, but we access it using global object called document (which lives inside window.document).

So, what is the difference?

While BOM controls the browser shell (window, tabs, history, screen size), DOM controls the actual HTML document rendered inside that window.

When the browser loads your HTML, it parses every tag into a hierarchical tree of objects. Through document, JavaScript can read, create, modify, and style elements on the fly.

For example:

// Grab element by ID
const heading = document.getElementById("main-title");

// Change text dynamically
heading.innerText = "JavaScript is running!";

// Change style directly
heading.style.color = "seagreen";

We can also listen to user interactions:

const btn = document.querySelector("#submit-btn");

btn.addEventListener("click", () => {
    heading.innerText = "Button clicked!";
});
