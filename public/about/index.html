About

By Dhymas Julyan Riyanto • July 30, 2019

What is Ngoding Kuy! ?

Ngoding Kuy! is a simple static tech blog built to share software engineering knowledge, technical experiences, and solve development problems together.

Initially, this blog was created as a personal archive for what the author is actively exploring and learning. Over time, it continues to evolve into a broader programming repository.

Why the name Ngoding Kuy! ?

To be completely honest, not entirely sure either.

It started because saying “kuy” (Indonesian slang for “yuk” / “let’s go”) was a frequent habit. Combining it with “ngoding” (coding) just felt fun, natural, and catchy.

This blog is always growing. If you spot any mistakes or have suggestions, feel free to reach out to the author.

Hopefully, this blog brings value to all of us.

Thank you!
