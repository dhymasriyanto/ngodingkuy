Javascript in Action

April 14, 2026 • By Dhymas Julyan Riyanto • [Javascript]

How does javascript control web and ur browser? So, basically there are two ways javascript control ur browser: BOM and DOM. BOM BOM stands for Browser Object Model, with it we can give special instructions over browser. In example: an attribute called ‘window’ we can make the browser show pop-up message with running alert() method in browser console. DOM DOM stands for Document Object Model, it is just like BOM, but we access it using global object called documents.
