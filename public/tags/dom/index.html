JavaScript 101: How JS Controls Your Browser (BOM vs DOM)

October 13, 2026

Welcome back to another note :') Most of us use JavaScript daily to build interactive UI, animate buttons, handle form submissions, or fetch backend APIs. But sometimes we overlook the foundational mechanics: how does JavaScript actually take control of your browser and web document under the hood? The whole mechanism boils down to two key concepts: BOM and DOM. 1. BOM (Browser Object Model) As the name implies, BOM represents the browser window and environment itself, completely independent of the actual HTML content loaded inside it.
